=== Grafana Loki Setup Notes ===

1. Started Loki locally using Docker:
docker run -d --name loki -p 3100:3100 grafana/loki:latest

2. Installed the Docker logging driver for Loki (if needed):
docker plugin install grafana/loki-docker-driver:latest --alias loki --grant-all-permissions

3. Ran the container with Loki log forwarding configured:
docker run --log-driver=loki --log-opt loki-url="http://localhost:3100/loki/api/v1/push" hello-devops:latest

4. Command to view the forwarded logs (using curl and jq):
curl -G -s "http://localhost:3100/loki/api/v1/query" \
  --data-urlencode 'query={compose_service="hello-devops"}' \
  | jq
